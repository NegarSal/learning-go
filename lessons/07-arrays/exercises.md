# Exercises - Arrays

1. Declare an array of 4 strings (`fruits`), assign values, print the array and its length, then change the second element and print it again.
2. Declare a string array (`colors`) using `[...]` and use `range` to print each index and value.
3. Declare a 2D integer array (`matrix`) with 2 rows and 3 columns, assign values, and use nested loops to print it as a grid.
